# WD Launcher + Termux Hybrid OS v3.0

Полнофункциональный проект гибридного Android-лаунчера в стиле Cyberpunk / Hacker OS со встроенным эмулятором терминала Termux.

## Состав архива
- `app/src/main/java/com/example/wdlauncher/MainActivity.kt` — Исходный код Android Activity с WebView контейнером.
- `app/src/main/assets/index.html` — Полнофункциональный HTML5/JS интерфейс терминала, графического меню и виджетов.
- `app/src/main/AndroidManifest.xml` — Настройки манифеста Android с разрешениями.
- `build.gradle.kts` & `settings.gradle.kts` — Конфигурация сборки Gradle.

## Основной функционал
1. **Эмулятор терминала (Termux Shell):** Команды `neofetch`, `apps`, `launch`, `top`, `weather`, `theme`, `play`, `clear`, `help`.
2. **Переключаемые темы:** `cyberpunk`, `matrix`, `dracula`.
3. **Графический лаунчер (GUI Mode):** Интерактивная сетка приложений с поиском.
4. **Системная телеметрия:** Наблюдение за CPU, RAM и часами в реальном времени.
